# Demo 跑通指南（30 秒上手）

> 这个 demo 默认开启 `useMock=true`，所有 API 请求自动 fallback 到 `utils/mock.js` 里的静态数据，**不需要后端、不需要真实 AppID、不需要域名**，打开微信开发者工具就能跑。

---

## 1. 启动

1. 打开「[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)」（必须用最新稳定版）
2. 左侧 **微信扫码登录**
3. 选择 **小程序项目 → 导入项目**
4. 填写：

   | 字段 | 值 |
   | --- | --- |
   | 项目名称 | `cdc-for-food` |
   | 目录 | `c:\Users\31911\Desktop\疾控\miniprogram` |
   | AppID | **测试号**（首次选"不使用云服务"，然后选"测试号"） |
   | 开发模式 | **小程序** |
   | 后端服务 | **不使用云服务** |

5. 点 **确定** → 模拟器编译

> **首次编译有可能提示** "当前开发者工具版本过旧"，按提示升级即可。

---

## 2. 启用本地调试选项

进入项目后：

1. 顶部菜单 → **详情**
2. 切到 **本地设置** Tab
3. **勾选**：
   - ☑ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
   - ☑ 不校验请求域名及 TLS 版本

> 这两项是 demo 跑通的关键 — 没勾的话 `wx.request` 会被微信直接拦截。

## 4. 想看真实接口？

打开 `miniprogram/utils/config.js`：

```js
useMock: false   // ← 改这一行
```

保存后模拟器会自动刷新。这时再操作页面：

- **如果后端没启动** → 页面会显示 "网络异常" toast（这是预期行为）
- **如果后端启动后** → 真数据返回

**当前 demo 不带后端**，要加后端请回到 `docs/miniprogram-devtools.md` 第 5 节。

## 5. 常见问题

### Q1 模拟器打开是白屏

- 检查 `miniprogram/app.json` 是否存在 → 一般是被杀软误删
- 微信开发者工具 → 详情 → **ES6 转 ES5** 要勾上

### Q2 报 `app.json: pages 字段必须是字符串数组`

- 这是 `app.json` 写错了。检查是不是用了引号包错位置（项目里已检查过 ✓）

### Q3 控制台打印 `[DEMO MODE] useMock=true`

- **这是正常的**，说明 demo 模式已开启

### Q4 真机预览发现页面空白

- 真机上 `wx.getPrivacyContract` 在基础库 < 3.0.0 会报 undefined，已在 `app.js` 做兼容
- 检查手机基础库版本：开发者工具右上角 → 详情 → 基础库 → 切换到 ≥ 3.0.0

### Q5 修改代码后模拟器没刷新

- 顶部菜单 → **编辑器 → 编译**（Ctrl+B / Cmd+B）强制刷新
