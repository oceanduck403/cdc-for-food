# 营养健康 AI 小助手 · 项目文档

> 成都市疾病预防控制中心 - 营养与食品安全科普小程序

## 📱 项目简介

营养健康 AI 小助手是一款基于微信小程序的营养健康科普工具，提供专业的营养评估、膳食指导、健康咨询和科普知识分享功能。

## 🎯 核心功能板块

### 1️⃣ 健康评估区 📋
- **功能**：健康问卷自填 / 医生填写
- **后端动态模板**（已接入真实数据库）：
  - 📋 **体重管理门诊首诊表**（20题）— 人口学信息、健康状况、饮食运动习惯
  - 🔄 **体重管理门诊复诊表**（16题）— 体重跟踪、饮食运动、症状变化
- **本地兼容问卷**（无网络时可用）：
  - 🍽️ 膳食调查问卷（15题）
  - 🏃 生活方式问卷（20题）
  - 💊 健康状况问卷（25题）
  - 🏥 食品安全问卷（18题）
- **特色**：
  - 支持单选、多选、文本输入
  - 分步骤填写，进度条显示
  - 历史记录查看（从后端加载）
  - 医生可通过专属链接为患者填写
  - AI 智能分析报告

### 2️⃣ 打卡指导区 🎯
- **功能**：每日打卡 + 健康指导
- **核心能力**：
  - 🍎 膳食打卡
  - 🏃 运动打卡
  - 💧 饮水打卡
  - 📸 拍照识别（AI分析）
  - 🚶 微信运动数据接入
  - 👥 群组指导（扫码入群）
  - 👨‍⚕️ 医生在线指导（免费预约）
- **AI 模板**：内置多种打卡场景的智能回复

### 3️⃣ 免费咨询区 💬
- **功能**：预约医生在线指导；各主页面悬浮球进入 AI 健康咨询
- **核心能力**：
  - 🤖 AI 聊天式咨询（使用次数以页面显示为准）
  - 📸 图片识别（精准 + 模糊识别）
  - 🍽️ 膳食信息自填
  - 🚶 微信运动接入
  - 🎁 每日打卡获得额外免费次数
- **快捷咨询**：
  - 膳食建议
  - 运动建议
  - 健康咨询
  - 食物禁忌

### 4️⃣ 科普互动区 📚
- **功能**：健康知识浏览与互动；后续对接疾控中心提供的科普素材
- **核心能力**：
  - 📖 知识库（6大分类）
    - 🥗 膳食指南
    - 🍄 毒蘑菇
    - 🔬 食品安全
    - 🦠 食源性疾病
    - 💉 疫苗科普
    - 🍎 营养知识
  - 🔍 关键词搜索
  - 🔥 热门文章推荐
  - 👍 文章点赞、收藏、评论与回复；消息中心查看互动和未读状态
  - 📚 科普素材后续由疾控中心提供，患者端不开放素材上传

## 🏗️ 技术架构

### 前端（小程序）
- **框架**：原生微信小程序
- **目录结构**：
```
miniprogram/
├── app.js              # 应用入口
├── app.json            # 全局配置（5个 tabBar 板块）
├── pages/
│   ├── index/          # 首页
│   ├── survey/         # 健康评估列表（动态加载后端模板）
│   ├── survey-form/    # 问卷填写（支持后端/本地两种模式）
│   ├── checkin/        # 打卡指导
│   ├── checkin-record/ # 打卡记录
│   ├── consult/        # 免费咨询
│   ├── consult-ai/     # AI 智能咨询
│   ├── science/        # 科普互动
│   ├── science-detail/ # 科普详情
│   ├── messages/       # 消息中心
│   ├── favorites/      # 我的收藏
│   ├── mine/           # 个人中心
│   ├── capture/        # 拍照识别
│   ├── profile/        # 健康档案
│   ├── login/          # 登录（患者/医生）
│   ├── admin/          # 管理员后台（含问卷管理）
│   ├── admin-login/    # 管理员登录
│   ├── doctor/         # 医生端
│   ├── doctor-chat/    # 医患聊天
│   ├── doctor-profile/ # 医生主页
│   ├── checkin/        # 打卡
│   └── survey/         # 问卷
├── components/         # 通用组件
├── utils/              # 工具方法
│   ├── api.js          # 后端 API 请求封装
│   ├── auth.js         # 登录鉴权
│   ├── survey.js       # 问卷 API（新增）
│   ├── admin.js        # 管理员 API
│   └── ...
└── images/             # 图片资源
```

界面图标统一使用本地矢量图标导出的 PNG。图标风格参考 [阿里巴巴矢量图标库](https://www.iconfont.cn/)，实际 SVG 来源、MIT 授权和颜色映射见 `images/ui/SOURCES.md`；无需在线加载图标。

### 后端（FastAPI）
- **框架**：Python FastAPI + SQLAlchemy
- **数据库**：MySQL（生产）/ SQLite（开发）
- **缓存**：Redis
- **AI 集成**：阿里云百炼千问 VL
- **路径**：`server/app/`

## 🚀 快速开始

### 本地运行
1. 在微信开发者工具中导入 `miniprogram/` 目录
2. AppID 填写你的小程序 AppID（或使用测试号）
3. 点击编译即可预览

### 配置项（`utils/config.js`）
```js
{
  qwen: {
    apiKey: 'sk-...',           // 阿里云千问 API Key
    baseUrl: 'https://dashscope.aliyuncs.com/compatible-mode/v1',
    model: 'qwen-vl-plus'
  },
  apiBase: 'https://your-domain/v1',  // 后端 API 地址
  useMock: true,                // demo 模式开关
  dailyAnalysisLimit: 20        // 单日分析次数上限
}
```
