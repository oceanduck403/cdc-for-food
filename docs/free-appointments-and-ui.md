# 主界面、免费预约与 UI 优化

患者登录后直接进入调查评估 tab，旧首页路由仅作兼容跳转。保留医生与管理员各自的工作台。

## 免费预约

- 打卡页“免费预约医生”进入咨询页并发起预约；咨询页也可以直接预约。
- 免费服务，没有医生收费或支付跳转。
- 没有在线接诊医生时，预约保存在服务端等待队列，支持取消。
- 医生登录并保持小程序在前台时，30 秒发送一次心跳；90 秒内心跳有效，同时账号启用、允许接诊的医生才参与自动匹配。
- 从在线医生中选择当前活动会话最少的一位。已有活动会话继续保留；医生短暂离线时显示可留言，避免自动切断服务。
- 医生上线心跳会处理等待队列。反复点击预约复用当前预约，患者锁与唯一约束防止重复建单。
- 管理员首页新增“预约调度台”，支持暂停/恢复医生接诊、指定/改派医生、重新排队、结束服务。
- 患者、医生及调度台在前台每 5 秒刷新；后台停止轮询。此处是轮询刷新，不是微信订阅消息或离线推送。
- 改派或结束后关闭旧会话，保留旧记录，并禁止旧会话继续发消息。
- `Appointment` 与 `DoctorPresence` 为独立新表，由现有启动建表流程创建，不清空原有数据库。

## 视觉与体验

主色 `#116B54`，暖白背景 `#F6F7F2`，统一绿色线性图标、卡片边距、按钮、标题层级与错误状态。图标源代码位于 `docs/generate-ui-icons.py`，主题位于 `miniprogram/styles/service.wxss`，主要服务页面引入共享样式。

问卷展示加载、空列表、失败重试和已完成状态；登记草稿按账户及模板保存于本机，模板题目变化后不自动套用旧草稿。打卡按真实日期重置，以去重后的日期计天数，不展示固定模拟步数或虚构热量；记录按账号在本机隔离，当前没有云端同步。

参考：微信官方 WeUI https://weui.io/1.x/ 的表单、导航与操作反馈；腾讯健康 https://yl.tencent.com/ 的服务入口与预约管理组织方式。没有复制品牌素材。

## 验证与上线边界

`node --test miniprogram/tests/*.test.js`：患者路由、预约状态、防重复点击、草稿隔离、跨日打卡、原有问卷回归。

在 server 目录运行 `.venv/Scripts/python.exe -m pytest tests -q`：角色权限、在线/离线匹配、取消、改派、结束、旧会话拒绝发送、并发重复预约与负载分配、既有接口回归。

微信开发者工具自带 wcc/wcsc 编译页面与样式；模拟器已实际打开登记表并从第一页进入第二页。真实手机的患者/医生/管理员三端联合操作仍需验收。代码未执行公网部署、微信上传、审核或发布。
