# 原始体重管理表单

问卷目录依据用户提供的两份 Word 转录，原稿不进入 Git。规范目录位于 `server/app/db/survey_catalog.json`，记录源文件名及 SHA256，可逐项对照题干、选项、分组和顺序。

| 原始表单 | 模板类型 |
| --- | --- |
| 体重管理门诊就诊信息登记表 | `weight_visit_registration` |
| 体重管理门诊病历首页 | `weight_basic_info` |
| 体重管理门诊首诊评估表 | `weight_clinic_first` |
| 体重管理门诊防肥分数自测表 | `weight_anti_obesity` |
| 体重管理门诊复诊评估表 | `weight_clinic_follow` |

登记表保留全部 10 个字段。病历首页保留体重、BMI、体脂百分比、内脏脂肪面积、腰围、腰臀比、小腿围、握力；纸表多次测量列对应按日期多次提交。首诊的疾病矩阵拆为各疾病及其用药情况，口味矩阵拆为盐、油、辣度。零食、含糖饮料等后续题目根据前题显示。防肥自测保留 36 道是非题和 11 个分组。重复出现在全套 Word 中的复诊表、防肥表各建立一个模板。

原稿未提供分值、计分公式或等级阈值。原始五表提交时 `total_score` 为 `null`，不能把缺少评分规则显示成零分或由示范逻辑计算分数。登记表仅保存登记信息；其余表可请求 AI 科普解读。AI 失败时保留答案、提交记录及当前页，并提供重试，不生成虚假的离线分析。

## 恢复与历史兼容

迁移 `0006_original_survey_catalog` 增加模板目录版本及提交时的题目快照，允许无分数的记录。迁移先复制旧提交对应的题目，再由启动逻辑恢复原稿，避免历史答案被新题干解释。

首次恢复将原始五表设为启用，停用原稿之外的 `healthy_lifestyle_self_check` 示范模板，保留其提交记录。每个模板通过 `catalog_revision` 标记已修复；后续重启不覆盖管理员修改或停用设置。开发初始化和正式启动共用同一目录，不再建立另一套近似题库。

小程序使用后端返回的模板 ID 进入详情，支持分组说明、条件跳题、日期、24 小时时间、小数输入及逐页填写。隐藏题目的残留答案不会提交；历史记录按提交时快照展示。服务失败显示重试入口，不以空白页面或示范模板替代。

## 验证

在仓库根目录运行 `node --test miniprogram/tests/*.test.js`；在 `server` 目录运行 `.venv\Scripts\python.exe -m pytest tests -q`。迁移测试覆盖旧记录快照及新模型一致性。电脑联调在开发版使用独立本地数据库与本机 API，不需要上传、审核或发布；正式包仍由发布脚本注入 HTTPS 地址。
