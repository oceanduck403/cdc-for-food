> 适用主体：成都市疾病预防控制中心
> 备案类型：网站备案（适用于小程序后端 API 域名）
> 办理入口：腾讯云 / 阿里云 / 华为云任一控制台 → 备案管理

## 二、腾讯云备案流程

### 2.1 第一步：登录腾讯云备案系统

1. <https://console.cloud.tencent.com/beian>
2. 用同一主体实名认证的腾讯云账号登录
3. 点击「开始备案」

### 2.2 第二步：填写主体信息

```
主体名称：成都市疾病预防控制中心
主体类型：事业单位
证件类型：事业单位法人证书
证件号码：[实际证书编号]
```

**注意**：主体信息必须与腾讯云账号实名认证完全一致，否则会被驳回。

### 2.3 第三步：填写网站信息

| 字段 | 值 |
| --- | --- |
| 网站名称 | 营养与食品安全 AI 小助手（API 服务） |
| 网站备案号 | 留空（首次备案自动生成） |
| 服务类型 | 网站 |
| 网站语言 | 中文 |
| 域名 | api.cdcdc-health.cn |

### 2.4 第四步：上传资料

依次上传：

1. 营业执照副本 / 事业单位法人证书（**彩色原件**，<5MB）
2. 法人身份证正反面
3. 域名证书（域名注册商处下载）
4. 主体负责人手持身份证照片

> **手持身份证照片要求**：
> - 正面免冠，五官清晰
> - 身份证信息完整可见
> - 纯色背景，建议白墙
> - 文件 < 3MB

### 2.5 第五步：视频核验

1. 腾讯云会通过小程序 / 微信推送视频核验请求
2. 法人本人出镜
3. 朗读随机数字（4 位）
4. 整个过程约 30 秒

### 2.6 第六步：等待审核

| 阶段 | 时长 |
| --- | --- |
| 腾讯云初审 | 1-2 个工作日 |
| 管局审核 | 7-20 个工作日（四川省通信管理局） |
| 合计 | 8-22 个工作日 |

审核期间可通过「备案管理」查看进度。

## 五、常见驳回原因

### 5.1 主体信息不一致

- **症状**：备案驳回「主体信息不真实」
- **解决**：确保云账号实名、备案主体、营业执照三者完全一致

### 5.2 域名未实名

- **症状**：「域名未实名认证」
- **解决**：域名注册商处完成实名（24 小时内）

### 5.3 负责人电话停机

- **症状**：核验电话无法接通
- **解决**：备案期间保持电话畅通

### 5.4 视频核验失败

- **症状**：「视频核验不通过」
- **解决**：重新录制，确保人脸清晰、声音清楚

### 5.5 资料不清晰

- **症状**：「证件模糊」「无法识别」
- **解决**：使用原件扫描，<5MB，分辨率 ≥ 300dpi

## 六、备案完成后

### 6.1 拿到备案号

```
川ICP备XXXXXXXX号-1（示例）
```

### 6.2 必须做的 3 件事

1. **网站底部添加备案号**（参考《非经营性互联网信息服务备案管理办法》）

   ```html
   <a href="https://beian.mps.gov.cn">
     川ICP备XXXXXXXX号-1
   </a>
   ```

2. **小程序后台添加备案号**
   - 微信小程序后台 → 设置 → 基本设置 → ICP 备案号

3. **备案号链接到工信部**（强制要求）
   - 链接地址：<https://beian.mps.gov.cn>
   - 不链接会被工信部处罚

### 6.3 每年例行核查

- ICP 备案信息核查（每年）
- 公安联网备案信息核查（不定期）
- 如主体信息变更，及时变更备案

## 七、备案与小程序上线的时间协调

```
T+0     提交 ICP 备案（关键路径，最长 20 天）
T+0     同时准备小程序开发（不依赖备案）
T+2     小程序账号企业认证（3-5 工作日）
T+10    ICP 备案 + 类目审核完成
T+12    公安备案完成
T+15    小程序提交审核 + 上线
```

> **备案期间**：开发照常进行，但服务器无法通过备案域名对外提供 HTTP 服务
> **替代方案**：使用临时 IP + 端口调试，备案通过后切换到正式域名
