# 合规与隐私

## 法规依据

- 《中华人民共和国个人信息保护法》
- 《中华人民共和国网络安全法》
- 《互联网医疗健康信息管理办法》（参考）
- 国家卫生健康委《国民营养计划》《健康中国行动》
- 《中国居民膳食指南（2022）》

## 数据收集原则

- **最小必要**：仅收集实现功能所必需的个人信息
- **明示同意**：通过隐私协议弹窗（`wx.getPrivacySetting`）取得用户明示同意
- **可撤回**：在「我的」页面提供撤销入口（V2 实现）

## 收集字段

| 字段 | 必要性 | 用途 | 存储位置 |
| --- | --- | --- | --- |
| openid | 必要 | 微信身份识别 | PostgreSQL |
| 昵称 / 头像 | 可选 | 个性化展示 | PostgreSQL |
| 手机号 | 可选（用户主动绑定） | 后续医患互动 | PostgreSQL |
| 年龄 / 性别 / 身高 / 体重 | 可选 | TDEE 计算 | PostgreSQL |
| 活动水平 | 可选 | 估算能量需求 | PostgreSQL |
| 健康备注 | 可选 | 个性化建议 | PostgreSQL |
| 膳食图片 | 必要 | AI 识图 | OSS + 分析后清理临时文件 |

## 第三方处理者

- 微信：登录身份与小程序运行环境
- 商用菜品识别 API：仅传输图片与必要元数据
- 对象存储服务：膳食图片

所有第三方均需签署数据处理协议（DPA）。

## 健康免责声明

应用涉及的所有建议、报告与营养计算结果均**仅供科普与个人参考**，不构成医学诊断或治疗意见。如有不适或慢病管理需求，请咨询专业医师与营养师。

## 安全措施

- 全站 HTTPS，强制 TLS 1.2+
- JWT 鉴权，密钥定期轮换
- SQL 参数化，禁止拼接
- 敏感字段（手机号、健康备注）加密存储（生产前启用 KMS）
- 操作日志审计（谁、什么时候、改了什么）
- 限流：每日分析次数上限，防止 API 滥用与成本失控

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| 用户数据泄露 | 加密 + 最小化 + 定期渗透测试 |
| 识别 API 成本失控 | 限流 + 图片压缩 + 无效场景过滤 |
| 健康建议被误解为医疗 | 多处免责声明 + 文案审核 |
| 微信类目审核不通过 | 立项期提前沟通，准备说明文档 |
| 等保未达要求 | 提前定级，留出整改周期 |
