# 阶段路线图

完整计划参见 Canvas：`nutrition-ai-plan.canvas.tsx`。

## 阶段一览

| 阶段 | 时间窗 | 关键交付 | 阶段门 |
| --- | --- | --- | --- |
| P0 立项与需求固化 | 第 1-2 周 | 需求矩阵、类目资质、PM 计划 | 需求基线签字 |
| P1 总体设计与原型 | 第 3-5 周 | 架构图、原型、知识数据清单 | 设计评审通过 |
| P2 MVP | 第 6-14 周 | 基础框架、AI 识图、个性化建议、知识库 V1 | 内测通过（≥30 用户） |
| P3 业务闭环 | 第 15-26 周 | 医患互动、知识库 V2、GIS 动态 | 业务试点报告通过 |
| P4 试点与验收 | 第 27-36 周 | 试运行、文档、培训、验收会议 | 验收合格 |
| P5 1 年咨询服务 | 2027-08 → 2028-07 | 工单响应、知识更新、API 优化 | 续约/扩展评估 |

## 关键里程碑

- **M1** 微信小程序审核通过上线（V1）
- **M2** 商用识别 API 接入并稳定运行
- **M3** 知识库 V2 上线（含食源性疾病 + GIS 动态）
- **M4** 验收会议通过，一次性结清
- **M5** 1 年咨询服务到期评估
