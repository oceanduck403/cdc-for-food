# 离线地图功能说明

## 概述

毒蘑菇风险地图功能支持离线使用，用户可以在没有网络的情况下：
- 查看预设的风险点位（内置数据）
- 查看和管理自己的标记点（本地存储）
- 定位当前位置（在有GPS的情况下）

## 功能特点

### 1. 离线数据

- **系统预设点位**：内置四川省内主要毒蘑菇风险区域数据，无需网络
- **用户标记存储**：保存在本地存储（LocalStorage），下次打开自动恢复
- **区域筛选**：支持按成都市、绵阳市、阿坝州等区域筛选

### 2. 用户标记功能

用户可以点击地图添加自己的标记点，包括：
- 标记名称
- 疑似品种
- 风险等级（高/中/低）
- 高发期
- 备注说明

### 3. 区域限制

- 仅支持四川省范围内的标记
- 系统预设点位覆盖成都、绵阳、德阳、雅安、阿坝、甘孜、凉山等地区

## 使用方法

### 查看地图

1. 打开「风险地图」页面
2. 默认显示成都地区为中心
3. 点击标记点查看详情

### 添加标记

1. 点击右上角「📍 标记」按钮进入标记模式
2. 在地图上点击要标记的位置
3. 填写标记信息表单
4. 点击「保存」

### 管理标记

- **查看标记**：点击标记点查看详情
- **删除标记**：在详情页点击「删除标记」
- **导出数据**：点击「📤 导出数据」保存为JSON文件
- **清空标记**：点击「🗑 清空标记」删除所有用户标记

### 区域筛选

1. 点击顶部区域选择器
2. 选择「成都市」「绵阳市」等
3. 地图自动筛选显示该区域的点位

### 定位

1. 点击右上角「📍 定位」按钮
2. 地图移动到当前位置
3. 如果当前位置不在四川省内，会提示「当前位置不在四川省内」

## 数据存储

### 本地存储

用户标记数据保存在小程序的本地存储中：

```javascript
wx.setStorageSync('userMarkers', JSON.stringify(markers));
```

### 数据格式

```json
[
  {
    "id": "user-1621234567890",
    "lat": 30.6586,
    "lng": 104.0648,
    "name": "我的标记点",
    "species": "疑似致命鹅膏",
    "level": "高风险",
    "period": "6-9月",
    "description": "在山路旁发现",
    "region": "成都市",
    "createdAt": "2026-08-26"
  }
]
```

### 数据导出

点击「导出数据」可以将标记数据导出为JSON文件，方便备份或分享。

## 离线模式

当检测到无网络时，页面顶部会显示「📴 离线模式」提示：

- 系统预设点位仍然正常显示
- 用户标记正常显示
- 添加新标记仍然可以操作
- 无法从服务器加载数据（但有本地缓存）

## 权限说明

### 位置权限

地图功能需要用户授权位置权限，用于：
- 定位当前位置
- 判断当前位置是否在四川省内

首次使用时会弹出授权提示，请选择「允许」。

### 存储权限

用于保存用户标记数据到本地。

## 技术实现

### 地图组件

使用微信小程序原生 `<map>` 组件，支持：
- GCJ-02 坐标系统（中国标准）
- 标记点显示
- 点击事件
- 定位

### 坐标系统

中国境内地图使用 **GCJ-02**（国测局坐标系），也称为"火星坐标系"。

### 数据同步

目前用户标记数据存储在本地，后续可以扩展：
- 云端同步（需要用户登录）
- 数据导入/导出
- 多人协作标记

## 常见问题

### Q: 为什么看不到地图底图？
A: 需要网络连接才能加载地图底图。离线模式下只能看到标记点。

### Q: 添加标记时提示「不在四川省内」？
A: 系统限制了只能在四川省范围内添加标记。请确认您选择的坐标在四川省边界内。

### Q: 标记数据会丢失吗？
A: 除非清除小程序数据或更换设备，否则标记数据会一直保留。建议定期导出备份。

### Q: 如何分享我的标记？
A: 点击「导出数据」可以将标记导出为JSON文件，通过微信分享给其他人。

## 地图服务商

微信小程序地图组件使用腾讯地图数据，支持：
- 街道地图
- 卫星地图（部分城市）
- POI搜索
