# 注册小程序 + 选类目 + 域名备案全流程

> 适用对象：一人团队，全新启动「营养与食品安全 AI 小助手」商用上线。
> 推荐路径：腾讯云 + 微信小程序 + 百度菜品识别（可替换）。

## 一、为什么选腾讯云

- 微信小程序与腾讯云账号体系打通，免二次实名
- 对象存储 COS 走内网回源微信生态
- 域名备案 + SSL 一站式
- 免费额度：轻量应用服务器、COS 50GB、CDN 流量包等

## 二、注册账号（4 个，必须同主体）

### 2.1 微信小程序账号

- 地址：<https://mp.weixin.qq.com>
- 流程：邮箱注册 → 选择主体类型（建议 **企业**，个人主体不能做医疗类目）→ 主体认证
- **费用**：企业认证 300 元/年
- **资质材料**：营业执照、法人身份证、对公账户验证（小额打款）
- **耗时**：材料齐全约 1-3 个工作日
- **拿到的关键值**：
  - **AppID**（`wx` 开头 16 位字符串）
  - **AppSecret**（后台 → 开发 → 开发管理 → 生成）
  - **原始 ID**（gh_ 开头）

> 个人主体也能注册，但类目受限、无法开通支付、不允许医疗咨询。**强烈建议企业主体**。

### 2.2 腾讯云账号

- 地址：<https://cloud.tencent.com>
- 流程：微信扫码注册（自动打通）→ 实名认证 → 学生/企业认证（可选）
- **费用**：实名免费；学生认证可领 25-35 岁云资源礼包
- **关键**：使用与小程序**同一主体的营业执照**

### 2.3 百度智能云账号（菜品识别）

- 地址：<https://cloud.baidu.com>
- 流程：手机号注册 → 实名认证 → 开通「图像识别 → 菜品识别」服务
- **费用**：免费试用 1000-2000 次；超出按次计费（约 0.01 元/次）
- **拿到的关键值**：
  - **API Key**
  - **Secret Key**
  - 接入文档：<https://cloud.baidu.com/doc/IMAGERECOGNITION/index>

### 2.4 阿里云账号（备用，可选）

- 用于替代腾讯云
- 地址：<https://cn.aliyun.com>

> 个人建议：先只注册腾讯云 + 百度，**别同时开多个云厂商账号**（账单混乱）。

## 三、域名注册 + 备案

### 3.1 注册域名

- 推荐服务商：**腾讯云 DNSPod**（已实名状态下 5 分钟注册）
- 后缀建议：`.cn` / `.com.cn` / `.com` 都可，价格 30-80 元/年
- 域名示例：
  - `cdcdc-health.com`（成都疾控）
  - `nutrition-ai.cn`
  - 避免：长横线、生僻词、与已有品牌近似

### 3.2 ICP 备案（**最慢的一步**）

- 入口：腾讯云控制台 → 备案管理
- 流程：填写主体信息 → 域名信息 → 网站信息 → 上传资料 → 视频核验 → 管局审核
- **耗时**：7-20 个工作日（取决于省份）
- **材料**：
  - 营业执照彩色扫描件
  - 法人身份证正反面
  - 法人手持身份证照片（核验用）
  - 网站负责人信息（可与法人一致）
  - 域名证书
  - 「互联网信息服务负责人承诺书」（腾讯云提供模板）

### 3.3 公安备案（30 天内）

- 备案完成后，还需到「公安部网络安全保卫局」做**公安联网备案**
- 入口：<https://beian.mps.gov.cn>
- 耗时：1-3 个工作日
- 必备，否则被查到会罚款

### 3.4 时间窗口提示

```
T+0    注册小程序 + 实名腾讯云 + 申请百度 API
T+1    企业认证通过（小程序 + 腾讯云）
T+2    域名注册 + 提交 ICP 备案
T+10   ICP 备案通过
T+13   公安备案通过
T+14   开始正式开发/部署
```

**备案期**就可以做开发，但无法对外发布。

## 四、AppID 与小程序后台配置

### 4.1 获取 AppID

1. 微信小程序后台 → 开发 → 开发管理 → 开发设置
2. 复制 **AppID（小程序 ID）**
3. 同时保存 **AppSecret（小程序密钥）**（妥善保存，重置需扫码）

### 4.2 替换到项目

```json
// miniprogram/project.config.json
{
  "appid": "wx替换成你的真实AppID"
}
```

同时把 `miniprogram/utils/config.js` 中的 `apiBase` 改为你的生产域名。

### 4.3 后台必配项

小程序后台 → 开发 → 开发管理：

| 项 | 填什么 |
| --- | --- |
| 服务器域名（request 合法域名） | `https://api.your-domain.com` |
| 服务器域名（uploadFile 合法域名） | `https://your-bucket.cos.ap-chengdu.myqcloud.com` |
| 服务器域名（downloadFile 合法域名） | 同上 |
| 业务域名（web-view） | 暂不需要 |
| 开发者微信号 | 你自己的微信 |

小程序后台 → 设置 → 基本设置：

| 项 | 填什么 |
| --- | --- |
| 小程序名称 | 营养与食品安全 AI 小助手 |
| 简称 | 营养 AI 小助手 |
| 小程序图标 | 108x108 PNG |
| 小程序简介 | 30 字内 |
| 服务类目 | 医疗 → 健康保健 → **营养咨询**（或「互联网医院」视资质） |
| 标签 | 健康、医疗、营养 |

### 4.4 服务类目选择（关键）

候选类目及对应资质：

| 类目 | 资质 | 审核难度 | 推荐 |
| --- | --- | --- | --- |
| 医疗 → 健康保健 → 营养咨询 | 营业执照即可 | ⭐⭐ | **首选** |
| 医疗 → 互联网医院 | 医疗机构执业许可证 + 互联网医院牌照 | ⭐⭐⭐⭐ | 不建议 |
| 工具 → 效率 | 无 | ⭐ | 容易但被拒（涉医） |
| 教育 → 在线教育 | 营业执照即可 | ⭐⭐⭐ | 表述需谨慎 |

**强烈建议**：选择「医疗 → 健康保健 → 营养咨询」，需在简介中明确**仅做营养与食品安全科普，不提供诊疗服务**。

> 类目审核 1-3 个工作日，被拒需要修改类目或补充材料，重新提交。
